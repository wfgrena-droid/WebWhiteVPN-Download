# WebWhite VPN

Официальные установочные файлы WebWhite VPN для Windows и Android.

## Скачать

Откройте [последний релиз](https://github.com/wfgrena-droid/WebWhiteVPN-Download/releases/latest) и выберите файл:

- **WebWhiteVPN_Setup.exe** — установщик для Windows x64.
- **WebWhiteVPN.apk** — основная версия Android (arm64).
- **WebWhiteVPN_Sergo.apk** — отдельная версия Android Sergo. Устанавливайте её только если вы уже пользуетесь Sergo.

Скачивайте обновление для своей версии приложения и устанавливайте поверх текущей, сохраняя профили. Android может попросить разрешить установку из выбранного источника.

## Подключение

1. Получите персональную URL-подписку в [Telegram-боте](https://t.me/WhiteWebVPN_bot).
2. Откройте ссылку и выберите WebWhite VPN либо добавьте URL в разделе «Мой VPN» приложения.
3. Выберите сервер и нажмите кнопку подключения.

## Обновления

Начиная с v2.2, сборка 8, приложение незаметно проверяет новые версии при открытии и периодически, пока оно активно. Окно появляется только при наличии обновления. Проверка не отправляет VPN-ключи или персональные подписки. Перед установкой проверяются размер и SHA-256 файла.

Обычное обновление можно отложить. Для версии ниже указанной минимально поддерживаемой отображается обязательное обновление. Установку подтверждает пользователь средствами Android или Windows. Если GitHub недоступен, неудачная проверка не блокирует приложение.

Старые версии без встроенной проверки нужно один раз обновить вручную.

## Поддержка

[Telegram-бот WebWhite VPN](https://t.me/WhiteWebVPN_bot).

В этом репозитории публикуются установщики и сведения о версиях. Исходники и ключи подписи здесь не размещаются.
