# WebWhiteVPN

**WebWhiteVPN** — простой VPN для Android без лишних настроек.

Приложение создано для быстрого подключения к WebWhiteVPN: добавляете свой ключ, нажимаете подключение — и Франсуа отправляется работать во Францию 🇫🇷🥖

## 📱 Android

Здесь публикуются официальные APK-релизы WebWhiteVPN для Android.

**Стоимость:** 200 ₽ / месяц  
**Пробный период:** бесплатно

### Что умеет WebWhiteVPN

- быстрое подключение и отключение VPN;
- работа с ключами WebWhiteVPN;
- маршрутизация: российские ресурсы могут работать напрямую, остальной трафик — через VPN;
- встроенная блокировка рекламы;
- отображение задержки до VPN-сервера;
- диагностика подключения;
- светлая и тёмная темы.

1. Скачайте и установите последнюю версию WebWhiteVPN.
2. Получите ключ WebWhiteVPN.
3. Добавьте ключ в приложение.
4. Нажмите **Подключить**.
