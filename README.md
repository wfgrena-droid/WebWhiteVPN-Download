# WebWhite VPN

VPN-приложение для **Windows и Android**, разработанное для подключения к WebWhite VPN. Добавьте персональную подписку, выберите сервер и включите VPN.

## Скачать актуальные версии — Windows и Android v2.3.6

- [Android — WebWhiteVPN.apk](https://github.com/wfgrena-droid/WebWhiteVPN-Download/releases/latest/download/WebWhiteVPN.apk) · Android 7.0 и новее, arm64.
- [Windows — WebWhiteVPN_Setup.exe](https://github.com/wfgrena-droid/WebWhiteVPN-Download/releases/latest/download/WebWhiteVPN_Setup.exe) · Windows x64.
- [Все версии и описание изменений](https://github.com/wfgrena-droid/WebWhiteVPN-Download/releases).

## Что умеет приложение

### На Windows и Android

- Добавление персональной **HTTPS URL-подписки** и совместимых **VLESS-ключей**.
- Выбор сервера и обновление списка серверов из подписки.
- Автоматическое переключение на рабочий сервер текущей URL-подписки при подтверждённом обрыве. Работающий сервер сохраняется независимо от пинга других узлов; ручное отключение отменяет восстановление.
- Подключение и отключение VPN с отображением состояния.
- Проверка работоспособности ключа через VPN; отображаемый пинг — медиана пяти TCP-замеров до входного адреса выбранного сервера. Успешные значения ниже 2000 мс учитываются даже при ошибках остальных замеров. Для цепочки серверов это задержка до входа, а не время загрузки сайта через весь маршрут. Доступные сведения о сроке подписки.
- Массовая проверка до 10 серверов одновременно: результаты появляются по готовности, при ошибке — «!».
- Автоматическая маршрутизация: российские сервисы напрямую, остальной трафик — по правилам VPN.
- Светлая, тёмная и системная темы.
- Поддержка и получение подписки через Telegram-бота.
- Тихая проверка новых версий и предложение обновления, когда оно доступно.

### Дополнительно на Android

- Индикатор запуска VPN после нажатия кнопки подключения.
- Блокировка известных рекламных и отслеживающих доменов. Некоторые виды рекламы могут оставаться.
- Выбор приложений, которые всегда должны использовать VPN, независимо от правил маршрутизации.
- Несколько вариантов оформления.

## Какие подписки поддерживаются

Протокол подключения — **VLESS**. Приложение распознаёт несколько форматов подписок:

- обычный список VLESS-ссылок, Base64 и Base64url;
- JSON sing-box/Karing: отдельный сервер, список или полная конфигурация;
- JSON Xray: отдельная конфигурация или массив конфигураций;
- YAML/JSON Clash/Mihomo с совместимыми VLESS-серверами.

Достаточно вставить HTTPS URL: приложение само загрузит и разберёт ответ. JSON одного сервера также можно вставить вручную. Названия и флаги берутся из подписки. Для загрузки поддерживаются HTTPS-перенаправления и gzip.

Поддерживаются совместимые параметры TCP/RAW, WebSocket, gRPC, HTTP/H2, HTTPUpgrade и XHTTP/SplitHTTP. Импорт серверов не заменяет настройки маршрутизации приложения чужими правилами.

**Совместимость с любой ссылкой не гарантируется.** Trojan, VMess, Shadowsocks и другие протоколы пока не добавлены в импорт. Некоторые дополнительные параметры и связанные цепочки конфигураций также могут не поддерживаться. Если подписка истекла, импорт её ответа не продлевает доступ.

Персональную ссылку подписки не публикуйте в открытых обсуждениях.

## Первое подключение

1. Получите персональную URL-подписку в [Telegram-боте WebWhite VPN](https://t.me/WhiteWebVPN_bot).
2. Откройте её в браузере и выберите «Открыть в приложении», либо скопируйте URL в раздел **«Мой VPN»** приложения.
3. Выберите сервер, откройте главный экран и нажмите кнопку подключения.
4. На Android при первом подключении разрешите создать VPN-соединение.

## Как обновить приложение сейчас

**Один раз скачайте актуальный файл по ссылке выше и установите поверх текущей версии. Не удаляйте приложение перед обновлением — так сохранятся профили.**

- **Android:** откройте APK и подтвердите установку. При запросе Android разрешите установку из выбранного источника.
- **Windows:** закройте WebWhite VPN, включая значок в трее, и запустите установщик.

После установки откройте приложение и проверьте подключение. Если GitHub не открывается или установка не получается, напишите в Telegram-бот поддержки.

Начиная с **v2.2, сборка 8**, приложение незаметно проверяет новые версии при открытии и периодически, пока оно активно. Окно появляется только при наличии новой сборки. В закрытом приложении фоновых push-уведомлений нет. Для установки пользователь подтверждает системный запрос Android или Windows.

Обычное обновление можно отложить. Если установленная сборка ниже минимально поддерживаемой, приложение показывает обязательное обновление. Неудачная проверка версии не блокирует работу VPN. Перед установкой проверяются размер и SHA-256 файла; персональные VPN-ключи и URL-подписки для проверки обновлений не отправляются.

**«Обновить подписку» и «Обновить приложение» — разные действия:** первая кнопка загружает серверы и параметры подписки, а новую программу устанавливают из APK или установщика.

## Поддержка

[Написать в Telegram-бот WebWhite VPN](https://t.me/WhiteWebVPN_bot).

Этот публичный репозиторий содержит общедоступные установщики и сведения о версиях. Исходники и ключи подписи здесь не размещаются.

В Windows v2.3.2 исправлено закрытие приложения при обновлении: установщик завершает его вместе со значком в трее штатной командой выхода и ждёт освобождения файлов. Android остаётся на v2.3.1.

В Windows v2.3.3 приложение запускается в умеренном окне по центру экрана с учётом масштаба Windows. Окно можно развернуть стандартной кнопкой и вернуть к начальному размеру.

В Windows v2.3.4 главная адаптируется к высоте окна: в обычном компактном окне одновременно видны кнопка, статус, пинг, подписка и выбранный сервер. На очень маленькой высоте прокрутка остаётся доступной.

В v2.3.5 обе версии сразу начинают тихую проверку обновлений при запуске. При смене сети запрос повторяется; найденное обновление не теряется при сворачивании или запросе разрешения VPN и предлагается после возврата в приложение, в том числе при работающем VPN. В Windows-установщике убраны запуск после установки и создание ярлыка на рабочем столе; существующие ярлыки не удаляются.

## Новое в v2.3.6


- Автоматическое переключение при подтверждённом обрыве: приложение проверяет доступные серверы текущей URL-подписки и выбирает рабочий. Поддерживаются и совместимые сторонние подписки.
- Рабочее подключение сохраняется: меньший пинг другого сервера сам по себе не вызывает переключение. Ручное отключение отменяет автоматическое восстановление.
- На Android проверка выполняется VPN-службой, в том числе при свёрнутом приложении. Если доступных серверов нет, проверки повторяются.
- Исправлены ложные блокировки рекламного фильтра Android, из-за которых могли не скачиваться файлы GitHub. Домены теперь сопоставляются по границам доменного имени. Исправленный список также доступен установленным версиям через обновление правил.

Устанавливайте поверх текущей версии без удаления приложения, чтобы сохранить профили. Android: 7.0+, ARM64. Windows: x64. При смене сервера текущие соединения могут прерваться и потребовать повторного открытия страницы.
