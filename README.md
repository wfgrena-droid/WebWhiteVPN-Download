## Новое в Android v2.3.11

- Исправлен бесплатный пробный период: приложение автоматически добавляет подписку с доступными серверами. Повторное получение восстанавливает действующий доступ без продления срока.

- Сохранённые ключи появляются сразу при запуске, без ожидания загрузки сетевых правил.
- Улучшено восстановление после переключения Wi-Fi и мобильной сети. Пинг автоматически перепроверяется, устаревшие результаты отбрасываются.
- При обновлении всех пингов неудачные проверки повторяются отдельно. Ошибка одного сервера не прерывает проверку остальных; логика общая для совместимых подписок разных провайдеров.
- Единый заголовок наших подписок — WebWhite VPN. Чтобы получить новое название, обновите подписку кнопкой облака.

Windows: v2.3.10 (без изменений).

## Возможности

- Импорт совместимых VLESS-подписок: текст/Base64, JSON sing-box/Karing и Xray, YAML/JSON Clash/Mihomo. Другие протоколы и некоторые параметры/цепочки пока не поддерживаются; совместимость со всеми URL не гарантируется.
- Выбор серверов, обновление подписок, до 10 параллельных проверок пинга. Сначала проверяется ключ запросом через VPN, затем показывается медиана успешных TCP-замеров до входного адреса сервера. Для цепочки это задержка до входа, а не весь маршрут. При неработающем ключе или отсутствии успешных замеров быстрее 2000 мс — «!».
- Автоматическое восстановление при подтверждённом обрыве через доступные серверы текущей URL-подписки, в том числе совместимой сторонней. Работающий сервер сохраняется независимо от пинга альтернатив; ручное отключение отменяет восстановление. При отсутствии рабочих вариантов проверки повторяются.
- Маршрутизация российских сервисов напрямую, остальных — по правилам VPN. Светлая, тёмная и системная темы.
- Android: индикатор подключения, дополнительные оформления, рекламный фильтр известных доменов и выбор приложений, которые всегда используют VPN. Вся реклама не гарантированно блокируется.
- «Поддержка → Не работает VPN»: локальная проверка серверов и подсказки, подключение по нажатию пользователя, переход в Telegram и резервную поддержку ВК. Отчёты и ключи автоматически не отправляются.
- Тихая проверка новых версий при возвращении в приложение и каждые пять минут во время работы, включая подключённый VPN. «Позже» откладывает предложение той же версии на шесть часов текущего сеанса, следующая версия обнаруживается независимо.

## Установка и обновление

Устанавливайте поверх текущей версии, не удаляя приложение: так сохранятся профили. Android попросит разрешить установку APK из выбранного источника и подтвердить обновление. На Windows закройте приложение, включая значок в трее, и запустите установщик.

Обновление приложения устанавливает новую программу. Кнопка облака обновляет список серверов вашей подписки. Персональная ссылка — индивидуальный ключ доступа, не передавайте её другим людям.

Подписка и поддержка: [Telegram-бот WebWhite VPN](https://t.me/WhiteWebVPN_bot). В репозитории размещены публичные установочные файлы; исходники и личные конфигурации здесь не публикуются.
