Это отдельные приложения для своих устройств. Устанавливайте обновления поверх старой версии, без удаления — подписки и настройки сохранятся. Возможность одновременного использования подписки определяется условиями её провайдера.

## 📺 Как начать на телевизоре

1. Установите ТВ-APK с флешки или откройте браузер телевизора и **введите в адресной строке [clck.ee/wwvpntv](https://clck.ee/wwvpntv)**. Нажмите «Скачать для телевизора» и установите APK. Поддерживаются Android 7+ и архитектуры ARM32 / ARM64 / x86_64; размер около 107 МБ.
2. Откройте **«Мой VPN → Добавить с телефона»**. Отсканируйте QR-код обычной камерой телефона, откройте страницу и вставьте URL своей подписки. Приложение на телефоне для этого необязательно. При обычной передаче телефон и TV могут быть в разных сетях; VPN можно оставить включённым.
3. В **«Мой VPN»** выберите сервер, затем в разделе **«Подключение»** нажмите **«Подключить VPN»** и подтвердите системное разрешение.
4. Можно выйти кнопкой «Домой» на пульте: VPN продолжит работать в фоне. Для отключения вернитесь в приложение и нажмите «Отключить VPN».

**Управление:** стрелки пульта перемещают выделение, OK выбирает пункт, «Назад» возвращает к предыдущему экрану.

- **☁ Облако у подписки** — обновить список серверов и настройки подписки.
- **⚡ Молния** — проверить пинг: у подписки — её серверы, на главном экране — выбранный сервер.
- **🗑 Корзина** — удалить подписку только с телевизора, с подтверждением. Покупку у провайдера это не отменяет.
- **«Настройки → Автозапуск при включении/перезапуске TV»** — включать VPN в фоне после запуска телевизора. Сначала подключите VPN вручную один раз. После ручного отключения автоматическое восстановление возобновится при следующем ручном подключении. Работа зависит от прошивки TV.
- **«Настройки → Обновления приложения»** — проверить новую версию. При работающем VPN приложение также проверяет обновления в фоне и может показать уведомление. Установку подтверждает пользователь.

Если текущий сервер перестаёт работать, приложение пытается переключиться на другой доступный сервер. Если недоступны все, автоматическое переключение не поможет.

## 📱 Чем поможет Android-приложение на телефоне

В версии с функцией **«Отправить на телевизор»** можно отправить уже добавленную совместимую URL-подписку: **«Мой VPN → ⋮ у нужной подписки → Отправить на телевизор»**, затем отсканировать QR-код с TV и подтвердить отправку. Поддерживаются и совместимые подписки других провайдеров.

**Если такого пункта в вашей версии ещё нет**, используйте обычную камеру телефона и страницу по QR-коду — обновлять или устанавливать мобильное приложение для этого не требуется. При передаче копируется выбранная подписка; постоянная синхронизация устройств не включается.

Windows, Android и TV используют общую систему обновлений: GitHub — основной источник, сайт — резерв для ТВ. Приложения получают только сборки своей платформы. Подписку на ПК можно добавить её URL-ссылкой; функции отправки с ПК на TV сейчас нет.

## Новое в Android v2.3.12

- Автопереключение быстрее выбирает первый проверенный рабочий сервер из доступных профилей. Логика не привязана к названиям или провайдеру.

## Возможности

- Импорт совместимых VLESS-подписок: текст/Base64, JSON sing-box/Karing и Xray, YAML/JSON Clash/Mihomo. Другие протоколы и некоторые параметры/цепочки пока не поддерживаются; совместимость со всеми URL не гарантируется.
- Выбор серверов, обновление подписок, до 10 параллельных проверок пинга. Сначала проверяется ключ запросом через VPN, затем показывается медиана успешных TCP-замеров до входного адреса сервера. Для цепочки это задержка до входа, а не весь маршрут. При неработающем ключе или отсутствии успешных замеров быстрее 2000 мс — «!».
- Автоматическое восстановление при подтверждённом обрыве через доступные серверы текущей URL-подписки, в том числе совместимой сторонней. Работающий сервер сохраняется независимо от пинга альтернатив; ручное отключение отменяет восстановление. При отсутствии рабочих вариантов проверки повторяются.
- Маршрутизация российских сервисов напрямую, остальных — по правилам VPN. Светлая, тёмная и системная темы.
- Android: индикатор подключения, дополнительные оформления, рекламный фильтр известных доменов и выбор приложений, которые всегда используют VPN. Вся реклама не гарантированно блокируется.
- «Поддержка → Не работает VPN»: локальная проверка серверов и подсказки, подключение по нажатию пользователя, переход в Telegram и резервную поддержку ВК. Отчёты и ключи автоматически не отправляются.
- Тихая проверка новых версий при возвращении в приложение и каждые пять минут во время работы, включая подключённый VPN. «Позже» откладывает предложение той же версии на шесть часов текущего сеанса, следующая версия обнаруживается независимо.

## Установка и обновление

Устанавливайте поверх текущей версии, не удаляя приложение: так сохранятся профили. Android попросит разрешить установку APK из выбранного источника и подтвердить обновление. На Windows закройте приложение, включая значок в трее, и запустите установщик.

Обновление приложения устанавливает новую программу. Кнопка облака обновляет список серверов вашей подписки. Персональная ссылка — индивидуальный ключ доступа, не передавайте её другим людям.

Подписка и поддержка: [Telegram-бот WebWhite VPN](https://t.me/WhiteWebVPN_bot). В репозитории размещены публичные установочные файлы; исходники и личные конфигурации здесь не публикуются.
