# WebWhite VPN

VPN-приложение для **Windows и Android**, разработанное для подключения к WebWhite VPN. Добавьте персональную подписку, выберите сервер и включите VPN.

## Что умеет приложение

### На Windows и Android

- Добавление персональной **HTTPS URL-подписки** и совместимых **VLESS-ключей**.
- Выбор сервера и обновление списка серверов из подписки.
- Подключение и отключение VPN с отображением состояния.
- Проверка задержки серверов и отображение доступных сведений о сроке подписки.
- Автоматическая маршрутизация: российские сервисы напрямую, остальной трафик — по правилам VPN.
- Светлая, тёмная и системная темы.
- Поддержка и получение подписки через Telegram-бота.
- Тихая проверка новых версий и предложение обновления, когда оно доступно.

### Дополнительно на Android

- Индикатор запуска VPN после нажатия кнопки подключения.
- Блокировка известных рекламных и отслеживающих доменов. Некоторые виды рекламы могут оставаться.
- Выбор приложений, которые всегда должны использовать VPN, независимо от правил маршрутизации.
- Несколько вариантов оформления.

## Какие подписки поддерживаются

**WebWhite VPN не является универсальным клиентом для любых VPN-сервисов.** Основной вариант подключения — персональная URL-подписка WebWhite VPN из нашего бота.

Загрузчик поддерживает совместимые VLESS-ссылки и подписки, возвращающие список VLESS-ссылок обычным текстом или в Base64. Поддержка отдельного протокола не означает поддержку всех его параметров и всех форматов подписок. URL другого сервиса может возвращать HTML-страницу, JSON/YAML-конфигурацию или данные для конкретного клиента — такая ссылка может не импортироваться. Совместимость со всеми сторонними подписками не обещается.

Если ваша сторонняя подписка не добавляется, используйте рекомендованный её поставщиком клиент. Саму персональную ссылку не публикуйте в открытых обсуждениях.

## Первое подключение

1. Получите персональную URL-подписку в [Telegram-боте WebWhite VPN](https://t.me/WhiteWebVPN_bot).
2. Откройте её в браузере и выберите «Открыть в приложении», либо скопируйте URL в раздел **«Мой VPN»** приложения.
3. Выберите сервер, откройте главный экран и нажмите кнопку подключения.
4. На Android при первом подключении разрешите создать VPN-соединение.

## Как обновить приложение сейчас

**Один раз скачайте актуальный файл по ссылке выше и установите поверх текущей версии. Не удаляйте приложение перед обновлением — так сохранятся профили.**

- **Android:** откройте APK и подтвердите установку. При запросе Android разрешите установку из выбранного источника.
- **Windows:** закройте WebWhite VPN, включая значок в трее, и запустите установщик.

После установки откройте приложение и проверьте подключение. Если GitHub не открывается или установка не получается, напишите в Telegram-бот поддержки.

Начиная с **v2.2, сборка 8**, приложение незаметно проверяет новые версии при открытии и периодически, пока оно активно. Окно появляется только при наличии новой сборки. В закрытом приложении фоновых push-уведомлений нет. Для установки пользователь подтверждает системный запрос Android или Windows.

Обычное обновление можно отложить. Если установленная сборка ниже минимально поддерживаемой, приложение показывает обязательное обновление. Неудачная проверка версии не блокирует работу VPN. Перед установкой проверяются размер и SHA-256 файла; персональные VPN-ключи и URL-подписки для проверки обновлений не отправляются.

**«Обновить подписку» и «Обновить приложение» — разные действия:** первая кнопка загружает серверы и параметры подписки, а новую программу устанавливают из APK или установщика.
